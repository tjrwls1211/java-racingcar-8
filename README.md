# 🏎️ 프리코스 2주차 과제 – 자동차 경주 게임
> 주어진 횟수 동안 여러 대의 자동차가 무작위 조건에 따라 전진하며, 최종 우승자를 출력하는 프로그램을 구현한다.

## 1. 요구 기능 목록

---
- [ ] 경주할 자동차 이름을 입력받는다.
   - 쉼표(,) 기준으로 구분한다.
   - 각 이름은 5자 이하만 가능하다.
- [ ] 시도할 횟수를 입력받는다.
- [ ] 각 자동차는 한 번의 시도마다 전진 또는 멈출 수 있다.
   - 0~9 사이의 무작위 값 중 4 이상이면 전진한다.
- [ ] 시도 횟수만큼 경주를 진행한다.
   - 매 시도마다 각 자동차의 결과를 출력한다.
- [ ] 경주 종료 후 우승자를 출력한다.
   - 가장 멀리 간 자동차(들)가 우승자로 선정된다.
   - 공동 우승 시 쉼표(,)로 구분해 출력한다.
  - [ ] 최종 출력 형식은 다음과 같아야 한다.
    - 차수별 실행 결과
    ```
    pobi : --
    jun : ----
    ryan : -
    ```
    - 최종 우승자
    ```
    최종 우승자 : jini
    ```
    - 공동 우승자
    ```
    최종 우승자 : pobi, jun
    ```
  
## 2. 예외

---
입력값이 아래 조건을 만족하지 않으면 `IllegalArgumentException` 발생 후 프로그램을 종료해야 한다.

- 자동차 이름이 공백이거나 5자 초과인 경우
- 자동차 이름이 중복된 경우
- 시도 횟수가 숫자가 아니거나 0 이하인 경우
- 이름 목록이 비어 있는 경우
